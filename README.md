# Jan's home page

A static Edge home page with a photo and a profile-switching reminder.

## Preview

Open `index.html`, or run `python3 -m http.server 8765` from this folder.

## Publish

GitHub Pages serves the root folder of the `main` branch. Push changes to update the page.

## Browser setup

Set the published URL as the home page and startup page in the profile that should show the reminder.
The page does not detect or change browser profiles. The arrow points toward the top-right toolbar.

The page requests search-engine exclusion. This is not access control; the published page remains public.
